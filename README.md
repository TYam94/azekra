# Azekra
Cosily-crafted, homely-made, and insanely-lovely square wheels.  

## Environment 
### Dependencies
 - Local installation of lmstudio
 - Local Zotero installation (when using Zotero-related features)
 - Several packages, documented in `pyproject.toml`

### How to set up
 1. Install lmstudio (https://lmstudio.ai/) and download LLM/Embeddings you want to use.
 1. Install and set up Zotero, if you are going to use Zotero-related features.
 1. Clone this repository to where you want.
 1. Run `uv sync` to install requried python packages.
